## 1. Descrição

O **ConectaCRM** é uma aplicação web desenvolvida com React, criada como parte de um projeto voltado à apresentação de uma solução para gestão e relacionamento com clientes.

Nesta etapa do projeto, a aplicação apresenta a proposta do **ConectaCRM**, a oportunidade identificada e os integrantes responsáveis pelo desenvolvimento.

O projeto possui uma interface organizada e responsiva, proporcionando uma experiência simples e intuitiva para a navegação entre as diferentes seções da aplicação.

---

## 2. Recursos

Atualmente, o projeto possui as seguintes páginas:

### 🏠 Home

Página inicial da aplicação, responsável por apresentar o ConectaCRM e sua proposta de forma objetiva.

### 📖 Sobre

Apresenta informações sobre o projeto, seu propósito e a solução proposta pelo ConectaCRM.

### 💡 Oportunidade

Apresenta a oportunidade identificada pela equipe e o problema que motivou o desenvolvimento da solução.

### 👥 Apresentação

Página destinada à apresentação dos integrantes da equipe responsável pelo desenvolvimento do projeto.

---

### Protótipo

O protótipo da aplicação foi desenvolvido utilizando o Figma.

## 6. Configuração e Execução

### 6.1 Clone o repositório

Para obter o projeto, clone o repositório utilizando:

```bash
git clone https://github.com/VidaConecta/ConectaCRM_react.git
```

Acesse a pasta do projeto:

```bash
cd ConectaCRM_react
```

### 6.2 Instale as dependências

Execute o comando:

```bash
npm install
```

### 6.3 Execute o projeto

Para iniciar o servidor de desenvolvimento, execute:

```bash
npm run dev
```

Após a execução, o Vite disponibilizará a aplicação em um endereço semelhante a:

```text
http://localhost:5173
```

Acesse o endereço apresentado no terminal utilizando seu navegador.

## 7. Estrutura do Projeto

A estrutura do projeto está organizada de acordo com as páginas e componentes desenvolvidos:

```text
ConectaCRM_react/
│
├── public/
│
├── src/
│   │
│   ├── assets/              # Imagens e outros recursos
│   │
│   ├── components/          # Componentes reutilizáveis
│   │
│   ├── pages/               # Páginas da aplicação
│   │   ├── Home/            # Página inicial
│   │   ├── Sobre/           # Informações sobre o projeto
│   │   ├── Oportunidade/    # Oportunidade identificada
│   │   └── Apresentacao/    # Apresentação dos integrantes
│   │
│   ├── App.tsx              # Componente principal
│   └── main.tsx             # Ponto de entrada da aplicação
│
├── package.json             # Dependências e scripts do projeto
├── tsconfig.json            # Configurações do TypeScript
└── vite.config.ts           # Configurações do Vite
```

> A estrutura acima deve ser ajustada caso a organização dos arquivos do projeto seja diferente.
